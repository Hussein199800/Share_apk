# المراحل 3–5: الإرسال، التحديث والإصدار، التحسينات

نُفّذت بتفويض المالك («تصرّف كما يتناسب») دون جولة مراجعة منفصلة.

## المرحلة 3: الإرسال المباشر
- **سجل الأجهزة (`PeerRegistry`):** يجمع الأجهزة من ثلاثة مصادر:
  - إعلانات UDP التي تبثها الأجهزة الأخرى.
  - ردودها على إعلاننا (`POST /register` إلى خادمنا، أو UDP بديلاً).
  - المسح اليدوي للشبكة الفرعية `/24` (احتياطي إذا حجب الراوتر البث).
- **إزالة التكرار:** حسب البصمة، مع تجاهل جهازنا.
- **`SendClient`:** يرسل `prepare-upload` (ينتظر قرار المستلم حتى 3 دقائق)، ثم `upload` لكل ملف مع التقدم، ثم `cancel` عند الإلغاء.
  - يرسل `sha256` بأحرف صغيرة، ويرسل امتداد `shareApk` (اسم الحزمة والإصدار).
  - النتائج: `Sent` / `Rejected` (403) / `Busy` (409) / `Failed`.
- **`SendController` (على مستوى التطبيق):**
  - الحالة: `Idle → Preparing → Waiting → Sending → Done/Rejected/Failed`.
  - تعمل الخدمة الأمامية أثناء الإرسال.
- **الاكتشاف عند إيقاف الاستقبال:** يبقى الاستماع والإعلان عند التحديث دون خادم، ويُكتشف الجهاز الآخر عبر رده بـUDP أو عبر المسح.
- **الواجهة:**
  - قائمة الأجهزة القريبة: الأيقونة حسب نوع الجهاز، وشارة «شارك أبك» أو «LocalSend».
  - زر تحديث، وإدخال عنوان يدوي.
  - بطاقة التقدم والنتيجة.
- **الاختبارات:** سجل الأجهزة، وإرسال كامل بين `SendClient` وخادمنا (قبول، رفض، انشغال، تطابق الملف)، ومسار التسجيل يضيف الجهاز.

## المرحلة 4: التحديث من GitHub والإصدار
- **`UpdateChecker`:**
  - يقرأ `releases/latest` ويقارن الإصدار الدلالي بإصدار التطبيق.
  - ينزّل ملف APK، ويتحقق قبل التثبيت من: اسم الحزمة، وأن الإصدار أحدث، ومطابقة التوقيع للتطبيق المثبت.
  - يثبّت عبر `PackageInstaller` الموجود.
- **ملاحظة:** المستودع خاص حالياً، فالتحديث لن يعمل حتى يصبح عاماً أو تُنشر الإصدارات في مستودع عام. تُعرض رسالة واضحة في هذه الحالة.
- **سير عمل `release.yml`:**
  - عند الدفع إلى `main` أو وسم `v*` يبني نسخة Release موقعة، بشرط وجود الأسرار التالية: `RELEASE_KEYSTORE_BASE64`، `STORE_PASSWORD`، `KEY_PASSWORD`.
  - ثم ينشر الإصدار مع `release-notes.md`.
- **إصدار التطبيق:** `versionName` يصبح 3.0.0، و`versionCode` يُرفع.
- **R8 لنسخة الإصدار:** مع قواعد حماية واسعة لمكتبات Netty وKtor وBouncyCastle وkotlinx.serialization وZXing.

## المرحلة 5: تحسينات مؤجلة من مراجعة المرحلة 1
- إجراء تحديث القائمة عبر قارئ الشاشة (TalkBack)، وزر تحديث في الحالة الفارغة.
- رفع الإشعار المؤقت فوق شريط التحديد.
- إزالة الفراغ الإضافي عند فتح لوحة المفاتيح.
- التمرير في شاشة الترحيب.
- ربط مفتاح المسح التلقائي بنصه.
- تخزين التدرجات مؤقتاً لتقليل إعادة الرسم.
- تلميح لبلاطة «مشاركة عبر رابط» عند عدم وجود تحديد.
- صلاحيات CI.
