# شارك أبك | ShareAPK

تطبيق أندرويد عربي (12 فما فوق) لاستخراج التطبيقات المثبتة ومشاركتها وتثبيتها، ولنقل التطبيقات والملفات بين الأجهزة القريبة على نفس الشبكة. **متوافق مع LocalSend**، ويعمل **بلا إنترنت ولا إعلانات ولا تتبع**.

## التبويبات
1. **التطبيقات:** كل التطبيقات المثبتة مع البحث والفلاتر والترتيب. تستطيع لكل تطبيق:
   - استخراجه كملف APK أو APKS (التطبيقات المقسّمة).
   - مشاركته، أو حفظه في التنزيلات، أو حفظه كملف ZIP.
   - عرض تفاصيله، وبصمة SHA-256 لتوقيعه وللملف.
   - إرساله مباشرة إلى جهاز قريب.
2. **الملفات:** أرسل ملفاً، أو صوراً وفيديو، أو مجلداً كاملاً، أو نصاً، أو محتوى الحافظة، إلى جهاز قريب.
3. **استقبال:** يظهر هاتفك للأجهزة القريبة التي عليها LocalSend أو «شارك أبك». عند وصول طلب:
   - تظهر نافذة قبول أو رفض.
   - **التطبيقات** تُقارَن إصداراتها بالمثبّت، ويظهر لها زر «ثبّت الآن».
   - **الملفات الأخرى** تُحفظ في `التنزيلات/ShareAPK`.
   - **الرسائل النصية** تظهر مع زر نسخ.
4. **المزيد:**
   - النسخ الاحتياطي الشامل قبل الفورمات، والاستعادة دفعة واحدة.
   - السجل، والتثبيت من ملف (APK وAPKS وXAPK وAPKM).
   - المشاركة عبر رابط مع رمز QR لجهاز لا يحمل التطبيق.
   - الإعدادات، والتحديثات، وحول التطبيق.

## الاستخدام مع LocalSend
- **الإرسال إلى LocalSend:** حدّد ما تريد إرساله، ثم «إرسال»، ثم اختر الجهاز.
- **الاستقبال من LocalSend:** افتح تبويب «استقبال»، ثم اختر اسم هاتفك من LocalSend على الجهاز الآخر.
- **الشبكة:** الجهازان على نفس الواي فاي، أو على نقطة اتصال من أحدهما. يعمل سواء كان التشفير مفعّلاً أو مطفأً في LocalSend.
- **إن لم يظهر الجهاز:** اضغط «تحديث» ليبحث في الشبكة كلها، أو أدخل عنوانه يدوياً.

## الخصوصية والأمان
- النقل مباشر بين الجهازين، ويُشفَّر عند دعم الطرف الآخر للتشفير، ويُقبل كل طلب يدوياً.
- التطبيق يتحقق من هوية الجهاز المستلم قبل الإرسال.
- لا يطلب صلاحية التخزين.
- التحديث من داخل التطبيق يتحقق قبل التثبيت أن الملف هو «شارك أبك» نفسه، وموقّع بنفس المفتاح، وأحدث من المثبّت.

## البناء
```bash
keytool -genkeypair -keystore debug.keystore -storepass android -alias androiddebugkey \
  -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug"
./gradlew testDebugUnitTest assembleDebug
```
- **التكامل المستمر:** كل دفع للكود يبني نسخة Debug ويشغّل الاختبارات، عبر `.github/workflows/android.yml`.
- **الإصدار:** الدمج في `main` ينشر نسخة موقّعة في صفحة الإصدارات، عبر `release.yml`، إذا أُضيفت أسرار التوقيع.

## البنية
| المجلد | المحتوى |
|---|---|
| `ui/` | الشاشات (Jetpack Compose)، ونظام التصميم، والتنقل |
| `receive/` | خادم LocalSend، والاكتشاف، والجلسات، والملفات المستلمة |
| `send/` | عميل الإرسال، والمتحكم، والتحقق من هوية الأجهزة |
| `update/` | التحديث من إصدارات GitHub |
| `installer/`، `backup/`، `wifi/` | المثبّت، والنسخ الاحتياطي، والمشاركة عبر رابط |
